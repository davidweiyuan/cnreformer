# Reformed Piety · 歸正靈命塑造

The active product is the Flutter app in [reformed_piety](reformed_piety/README.md), prioritizing iPhone/iPad testing before Android. It provides devotional articles from davidweiyuan.wordpress.com and streaming videos from @davidweiyuan, with account-free offline reading and local saved state.

- [Agreed product specification](docs/PRODUCT_SPEC.md)
- [Run and implementation notes](reformed_piety/README.md)
- [TestFlight release gates](docs/TESTFLIGHT_PLAN.md)

`CNReformer/` is the original SwiftUI prototype, retained for reference. `Cornerstone-DocApp/` is a separate local reference project and is not part of the Flutter app.
